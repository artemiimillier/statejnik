# Заголовок статьи - 3 варианта (Этап 3)

> **Метод (Этап 3 методологии).** Заголовок пишется для человека, который за 1 секунду должен понять, **что он сделает, прочитав статью, и зачем это ему**. Если тот же заголовок совпадает с тем, как человек гуглит - это и есть хороший SEO. Обратное неверно: «совпадает с ключевым запросом» != «понятно человеку».
>
> Заполняй сверху вниз: сначала интент, потом классификация термина, потом формула, потом 3 варианта. Не пропускай шаги.

## Шаг 3.3 - Формула заголовка по типу термина

- **Якорь:** `<Термин>: <утилитарный хвост>`
- **Жаргон:** `Как <глагол> <объект> через <термин>: <как именно>`

Главная проверка для жаргонной темы: прикрой пальцем всё после «через». Осталось понятно человеку без термина - валидно. Без термина теряет смысл - переписывай.

## Шаг 3.4 - Три варианта (human-first / search-first)

> Требования: вариант 1 - без термина в первых 30 символах (действие в начале); вариант 2 - с термином рядом с ключевым словом; все 3 проходят human-test (звучат как живая фраза из разговора); длина 50-70 символов.

### Вариант 1 - human-first (без термина в первых 30 символах) → топ-1 по умолчанию

